# Personal Portfolio Website

A simple personal portfolio website created using **HTML and CSS**.  
The website provides a brief introduction about me and a way for visitors to get in touch.

## 🌐 Pages

- **Home** – Contains my introduction and basic information.
- **Contact** – Allows visitors to get in touch with me.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Simple and clean design
- Easy navigation
- Responsive layout
- Beginner-friendly HTML and CSS
